# Documentation agent instructions

- Người đọc chính là kỹ sư, chuyên viên HCNS và người phê duyệt rủi ro.
- Viết tiếng Việt rõ ràng; giữ tên interface/code bằng tiếng Anh.
- Không lặp README. README định hướng; `docs/` giải thích quyết định và vận hành.
- Mọi tuyên bố độ chính xác phải dẫn tới dataset, phiên bản model và metric.
- Không ghi PII, OCR text thật, endpoint nội bộ hoặc secret vào ví dụ.
- Khi thêm tài liệu, cập nhật mục routing trong root `AGENTS.md`.
- ADR chỉ ghi quyết định khó đảo ngược; không dùng ADR làm nhật ký.
