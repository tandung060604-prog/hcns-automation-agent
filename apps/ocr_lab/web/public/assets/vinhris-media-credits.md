# VinHRIS hero media

The hero uses a local copy of free stock media. The page only plays the first 26 seconds of each asset so the opening loop stays in the requested 20–30 second range.

- Video: [Business people at work meeting](https://mixkit.co/free-stock-video/business-people-at-work-meeting-4809/), Mixkit asset 4809, 37 seconds. Source file: `vinhris-hero-source.mp4`.
- Music: [Close Up](https://mixkit.co/free-stock-music/corporate-music/), by Michael Ramir C., Mixkit asset 1167. Source file: `vinhris-hero-music.mp3`.
- License: [Mixkit License](https://mixkit.co/license/). Both assets were selected from the free stock video/music collections and stored locally rather than hotlinked.
